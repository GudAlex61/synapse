# Synapse: новый layout и fullscreen-чат

Архив подготовлен поверх загруженной версии ветки `main`.

## Обычный режим

- слева: видеоплеер, затем чат;
- справа: выбор видео, ссылки и дополнительная информация.

## Расширенный режим

Над видео появилась кнопка **«Полный экран»**.

В расширенном режиме:

- на ПК и телефоне в горизонтальной ориентации чат открывается справа;
- на узком экране в портретной ориентации чат размещается снизу;
- кнопка **«Скрыть чат / Показать чат»** переключает режим без выхода;
- выбор запоминается в браузере;
- кнопка **«Свернуть»** и клавиша Escape закрывают режим;
- если браузер не разрешает Fullscreen API для блока, используется визуально полноэкранный fixed fallback.

## Применение изменённых файлов

Скопируйте папки `components` и `app` из changed-архива в корень репозитория с заменой файлов, затем:

```bash
pnpm test
pnpm typecheck
pnpm build
git add components/watch-room.tsx components/video-player.tsx app/globals.css
git commit -m "Add fullscreen chat layout"
git push origin main
```
