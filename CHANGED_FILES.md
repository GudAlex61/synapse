# Изменённые файлы

- `components/watch-room.tsx`
  - чат перенесён под видеоплеер в обычном режиме;
  - блок выбора видео и дополнительная информация размещены справа;
  - добавлен расширенный полноэкранный режим комнаты;
  - в полноэкранном режиме чат можно показать или скрыть;
  - выбранный режим чата сохраняется в `localStorage`;
  - добавлен CSS fallback для iPhone и браузеров без element Fullscreen API;
  - добавлен выход по Escape.

- `components/video-player.tsx`
  - добавлен `className` для адаптации размера плеера;
  - видео использует `object-contain` в расширенном режиме;
  - штатная fullscreen-кнопка браузера отключена там, где поддерживается, чтобы использовать режим с чатом.

- `app/globals.css`
  - скрыта WebKit fullscreen-кнопка нативных video controls, поскольку приложение предоставляет собственную кнопку.

SQL-миграции не требуются.
